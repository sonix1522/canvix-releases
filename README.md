# Canvix releases

Installers for **Canvix**, a canvas-based task tool. This repo only holds the releases;
installed copies of Canvix check it for updates when they start.

## Download

Get the newest version from **[Releases → Latest](https://github.com/sonix1522/canvix-releases/releases/latest)**:

- `Canvix_<version>_x64-setup.exe`: installer (recommended)
- `Canvix_<version>_x64_en-US.msi`: the same as an `.msi` (use one or the other)
- `Canvix_<version>_portable.exe`: runs without installing (doesn't update itself)

## Updates

Canvix 0.2.0 and newer offer new versions automatically when they start
(you can also use Settings → Misc → Check for updates). Your tasks and settings live in
`%APPDATA%\SonixTools\` and are kept when you update.
